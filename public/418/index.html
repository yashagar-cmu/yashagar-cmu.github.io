GPU-Accelerated Computational Lithography Simulation

15-418/618 Final Project, Fall 2026

Team Members: Yash Agarwal, Daniel Fields

Project URL: https://yash-agarwal.org/418

Summary

We plan to implement and optimize a GPU-based computational lithography simulator using C++ and CUDA. We will first implement a baseline simulator using full-resolution FFTs, and then implement a more efficient algorithm that reduces the sizes of the intermediate FFTs. We will experiment with several parallelization strategies, including batching optical computations, parallel reductions, memory layout optimizations, and kernel fusion, and compare their performance on NVIDIA GPUs.
